# RARE CARD HUNTER 導入・公開手順

## できること
- カードの手動登録・編集・削除（詳細・編集画面の削除ボタン）
- カード名・番号・テキスト、文明、コスト、レアリティ、種族による複合検索
- 所持枚数の増減・直接入力、購入リスト、ショップ用メモ
- カード画像・案内キャラクター画像・背景画像の登録
- IndexedDBへの端末内保存、画像を含むJSONバックアップ・復元
- PWAホーム画面追加、静的ファイルのオフラインキャッシュ

## 公開前の注意
PWAはHTTPSで配信する必要があります。GitHub PagesのURLは公開URLです。ただしアプリのカード情報・画像はIndexedDBに保存され、アプリからサーバーへ送信しません。公開リポジトリに利用者データを置かないでください。

## GitHub Pages（初心者向け）
1. ZIPをPCで解凍します。
2. https://github.com/ でアカウントを作成・ログインします。
3. 右上の「＋」→「New repository」を選択します。
4. Repository nameに `rare-card-hunter` と入力し、Publicを選んで作成します（Pagesを使うため。個人データは公開されません）。
5. リポジトリ画面の「Add file」→「Upload files」を選び、解凍したフォルダ内のファイル一式をアップロードしてCommitします。フォルダごとではなく、その中の `index.html` がリポジトリ直下に来るようにします。
6. Settings → Pages → Build and deployment で「Deploy from a branch」、Branchを `main`、Folderを `/ (root)` にしてSaveします。
7. 数分待ち、Pages欄に表示された `https://ユーザー名.github.io/rare-card-hunter/` を開きます。
8. Android ChromeでURLを開き、メニュー（︙）→「ホーム画面に追加」または「アプリをインストール」を選びます。表示はChromeのバージョンにより異なります。
9. 更新時は同じリポジトリへ修正ファイルをアップロードしてCommitします。Service Workerのキャッシュ名を変えると更新反映が確実です（例：`rare-card-hunter-v2`）。

## バックアップ・復元
設定（歯車）→「バックアップを書き出す」でJSONを端末へ保存します。復元は「バックアップを復元」からJSONを選びます。復元は現在のデータを上書きするため、確認画面が出ます。端末・ブラウザのデータ消去や別端末への移行に備えて定期的に書き出してください。

## 公式カード情報の自動取得について
公式またはDM Wikiのカード詳細URLを入力し「公式 / Wikiから取得を試す」を押します。ブラウザからの `fetch` を試み、取得可能な場合に限りページタイトル・description・表形式のカード項目をフォームへ反映します。公式サイトがCORSを許可しない場合、アクセス制限、ページ構造変更等では取得できません。失敗時に成功したように表示せず、URLを出典として保存して手入力へ誘導します。DM Wikiは有志編集型で、Wiki自身も記載内容の誤り等の可能性を案内しています。必ず登録前に確認してください。公式APIの存在・利用許諾および各サイトのCORS許可は本パッケージでは確認・保証していません。公式ページを開いて内容を確認し、必要な項目を手入力してください。

## 制限事項・既知の未実装
- 本パッケージはこの実行環境からGitHubへ公開していません。公開URLは未発行です。
- Android実機での実機テストは未実施です。PCブラウザのHTTPS環境で確認後、Androidでテストしてください。
- 公式サイトのAPI・利用条件・CORS許可は未確認で、自動取得はベストエフォートです。
- 画像はJPEGへ縮小変換し、1ファイル8MB以下を受け付けます。ブラウザのストレージ容量には端末依存の上限があります。
- 案内キャラクターは画像を利用者がアップロードする前提です。ぴょんこ姫の画像は同梱していません。
- 画面は基本機能を実装した試作版です。登録済みカードの削除、カードタイプ等の検索フィルター、複数キャラクター管理、より詳細な公式情報パーサーは未実装です。
- JSONバックアップは画像Data URLを含むためファイルが大きくなることがあります。
- Safari等を含む全ブラウザ互換性は保証しません。Android Chromeを想定しています。

## セキュリティ
アプリはカードデータをIndexedDBへ保存し、通常操作で外部送信しません。通信する外部先は利用者が開く公式カードページと、アプリ本体を配信するGitHub Pagesです。GitHub Pages上のHTML/JSは公開されるため、秘密情報や個人カードデータをソースへ書き込まないでください。

## 情報源について（2026-11-02）
DM Wiki（https://dmwiki.net/）を補助情報源として追加しました。同Wikiは共同編集型のファンサイトであり、情報の誤りがあり得る旨を自ら説明しています。出典URLを保存し、内容を確認してから登録してください。

## 公式サイトの確認結果（2026-11-02）
公式カード検索ページは公開されており、検索条件としてカード名・読み・テキスト・種族・文明・コスト・カード種類・レアリティ等が確認できます（[公式カード検索](https://dm.takaratomy.co.jp/card/)）。ただし、今回の調査では一般利用者向けAPIや外部サイトからの取得を許可するCORS設定・利用許諾を確認できませんでした。そのためアプリは公開APIがあると仮定せず、公式URLを利用者が入力しブラウザfetchを試す方式です。CORS拒否時は手動入力へ切り替えます。
タカラトミーのFAQは、サイト掲載画像・動画等について、著作権法上認められる場合を除き権利者の許諾なく使用できない旨を案内しています。カード画像やキャラクター画像はアプリに同梱せず、利用者自身が利用権限を持つ画像を端末内に追加する設計としています。


## v1.3.0 アップデート内容

- ホーム画面のナビゲーター画像を大型化。設定から100〜320pxで調整できます。
- カード画像をアップロードし、Tesseract.js（日本語・英語）でOCRできます。OCRエンジンと言語データは初回利用時にCDNから取得するため、インターネット接続が必要です。画像はブラウザー内で処理し、OCR目的でサーバーへ送信しません。読み取り誤りがあるため、必ず内容を確認してから保存してください。
- OCRしたカード名を使って公式カード検索とDM Wikiの検索ページを開けます。候補の正誤はユーザーが確認してください。
- 対応する公式・WikiページURLから、ページ情報とカード画像の取得を試みます。サイトのCORS設定や画像ホストの制限により取得できない場合があります。その場合はページを開き、画像を端末に保存してアップロードしてください。
- DM Wikiは有志編集の情報源です。誤りや更新遅れの可能性があるため、公式情報と照合してください。

## アップデート時の注意

既存データは同じサイトURL・同じIndexedDBを使う限り、通常は保持されます。ただし、アップデート前にアプリの「設定」→「バックアップを書き出す」でJSONバックアップを保存してください。GitHubでは既存ファイルと同じパスへ新しいファイルをアップロードし、上書きコミットします。リポジトリやURLを作り直さないでください。


## v1.2.0 アップデート内容

- ホーム画面の案内メッセージ初期値を「わたしたちはレアカードハンター！」に変更しました。設定から任意の文言に変更できます。
- カード画像の選択欄は `accept="image/*"` を使用し、Androidの写真ピッカーやGoogleフォト、端末ファイルアプリなどから画像を選びやすくしました。端末・ブラウザにより表示される選択画面は異なります。アプリが端末の写真ライブラリ全体を直接走査するわけではなく、ユーザーが選んだ画像だけを読み込みます。
- カード名入力中に、端末内に登録済みのカード名候補を表示します。候補を選ぶと登録済み情報をフォームへ反映できます。未登録カードは公式カード検索またはDM Wiki検索へ移動して確認できます。外部サイトから候補一覧を自動取得する機能ではありません（CORS等の制約があるため）。
- Service Workerのキャッシュ名を更新し、新しいファイルを読み込みやすくしました。

## v1.2.0 の注意

写真アプリの画像は、Androidのシステム写真選択画面に表示された画像からユーザーが選択する方式です。Googleフォトのクラウド上のみの画像など、端末側でダウンロード・選択できない画像は、先に端末へ保存する必要がある場合があります。
