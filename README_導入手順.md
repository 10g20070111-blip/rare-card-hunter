# RARE CARD HUNTER v2.0.0

## 更新内容
- メイン画面を「カードを登録する」「購入予定のカード」「設定」の3つのコンソールに整理。
- メインメッセージを大きく表示。キャラクター画像と吹き出し表示を設定可能。
- ナビゲーターの「だわさ」口調を復活。
- 公式サイトまたはDM Wikiのカード詳細URLから、カード名・コスト・テキスト・コレクター番号・画像の取得を試行。
- 読み取り専用の確認画面と編集画面を分離し、「登録」「キャンセル」を用意。
- 旧版と同じIndexedDB（rare-card-hunter）を使用し、登録済みカードを保持する設計。

## 更新手順
1. 先にアプリの「設定」からバックアップを書き出してください。
2. ZIPを解凍し、中の `rare_card_hunter` フォルダにあるファイルをGitHubリポジトリの直下へアップロードして置き換えます。
3. `index.html`、`style.css`、`app.js`、`service-worker.js`、`manifest.json`、`icon.svg` を配置します。
4. GitHubでCommit changesし、Pagesの反映を待ちます。
5. アプリを閉じてURLをChromeで再読み込みします。

## URL取得についての重要事項
GitHub Pagesだけで動く静的アプリのため、公式サイトやWikiがブラウザからの外部読み込み（CORS）を許可していない場合、URLからの自動取得は失敗します。これはアプリ側だけでは回避できません。ページごとのHTML構造によって抽出できる項目も異なります。取得できた内容を確認し、必要なら編集してください。


## v2.1.0 カードURL取得について

- 対応URLはデュエル・マスターズ公式サイト（dm.takaratomy.co.jp）とDM Wiki（dmwiki.net）のHTTPSページです。
- GitHub Pagesは静的サイトのため、取得先のCORS制限を直接回避できません。本版ではJina Readerを経由してページ本文を取得し、カード名・コスト・番号・カードテキスト・画像URL・追加情報を抽出します。
- 外部読み取りサービスの混雑・制限・対象ページ構造の変更で取得できない場合があります。取得結果は登録前に確認し、不足分は「編集する」で補ってください。
- 外部サービスにカードページURLを送信して取得します。個人情報や非公開URLは入力しないでください。
- 既存データはIndexedDBに保存されます。更新前にアプリの「設定」からバックアップを書き出してください。
