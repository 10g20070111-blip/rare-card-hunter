RARE CARD HUNTER v2.6.0

【更新手順】
1. アプリの「設定」から登録データのバックアップを保存してください。
2. このZIPを解凍します。
3. rare_card_hunter フォルダ内のファイルを、GitHubリポジトリ直下の同名ファイルへ上書きしてください。
   index.html / app.js / style.css / service-worker.js / manifest.json / icon.svg
4. GitHubで変更をコミットします。
5. 公開サイトを開き直し、画面下部が VERSION 2.12.0 になったことを確認してください。
6. 古い画面が残る場合は、サイトを開いた状態でブラウザの再読み込みを行い、必要ならアプリを完全終了して再起動してください。

【カード情報取得について】
・HTTPSのデュエル・マスターズ公式サイトまたはDM WikiのURLを受け付けます。
・ブラウザから対象サイトを直接取得せず、Jina Readerを経由してページ内容を読み取ります。
・ページの構造や外部サービスの応答によって、一部の項目（特に画像）が取得できない場合があります。その場合は「編集する」から補完してください。
・外部読み取りサービスを利用するため、通信環境やサービス側の制限により取得できない場合があります。

【データについて】
通常のファイル更新ではIndexedDB内の登録カード・設定は削除されません。念のため更新前にバックアップしてください。


【v2.6.0の追加機能】
・ナビゲーターの口調に「お嬢様口調」を追加しました。
・種族欄を横幅いっぱいにし、複数種族の「/」の直前で改行できるようにしました。
・公式カードページのカード名抽出を改善し、DMEXなど「19/68」形式の番号にも対応しました。
・登録カードをコスト順／文明順／名前順／追加した順で並べ替えできます。文明順は火→水→闇→光→自然→無色です。
・登録カードの検索欄を追加しました。名前・文明・種族・カードテキストなどから候補を絞り込めます。

【更新時の注意】
通常のファイル上書きではIndexedDBの登録カード・設定は削除されませんが、念のため更新前にバックアップしてください。
